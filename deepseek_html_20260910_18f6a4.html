Request Flow

  1. User opens http://<server>:9090
  2. Nginx (frontend container) serves Angular HTML/JS
  3. Browser executes Angular → calls /api/users (relative path)
  4. Browser sends request to http://<server>:9090/api/users
  5. Nginx proxies /api/ → http://backend:2002/api/users
  6. Spring Boot receives request
  7. Spring calls UserService → UserRepository → Hibernate
  8. Hibernate queries MySQL at mysqldb:3306
  9. MySQL returns rows
  10. Spring serializes to JSON
  11. Nginx relays response to browser
  12. Angular renders table

4.5 API Service

File: src/app/services/user.service.ts

import { Injectable } from '@angular/core';
import { HttpClient, HttpErrorResponse } from '@angular/common/http';
import { Observable, throwError } from 'rxjs';
import { catchError } from 'rxjs/operators';
import { User } from '../models/user.model';

@Injectable({ providedIn: 'root' })
export class UserService {
  // Relative path — Nginx proxies /api/* to backend container
  private readonly API_BASE = '/api/users';

  constructor(private http: HttpClient) {}

  getAll(): Observable<User[]> {
    return this.http.get<User[]>(this.API_BASE)
      .pipe(catchError(this.handleError));
  }

  getById(id: number): Observable<User> {
    return this.http.get<User>(`${this.API_BASE}/${id}`)
      .pipe(catchError(this.handleError));
  }

  create(user: User): Observable<User> {
    return this.http.post<User>(this.API_BASE, user)
      .pipe(catchError(this.handleError));
  }

  update(id: number, user: User): Observable<User> {
    return this.http.put<User>(`${this.API_BASE}/${id}`, user)
      .pipe(catchError(this.handleError));
  }

  delete(id: number): Observable<void> {
    return this.http.delete<void>(`${this.API_BASE}/${id}`)
      .pipe(catchError(this.handleError));
  }

  private handleError(error: HttpErrorResponse) {
    let message = 'Something went wrong';
    if (error.error instanceof ErrorEvent) {
      message = `Client error: ${error.error.message}`;
    } else if (error.error?.errors && typeof error.error.errors === 'object') {
      message = Object.entries(error.error.errors)
        .map(([f, m]) => `${f}: ${m}`).join(', ') || error.error.message;
    } else {
      message = error.error?.message || `Server error: ${error.status}`;
    }
    console.error('[UserService]', message, error);
    return throwError(() => new Error(message));
  }
}

5.8 CORS Configuration

File: config/CorsConfig.java

@Configuration
public class CorsConfig implements WebMvcConfigurer {

    @Override
    public void addCorsMappings(CorsRegistry registry) {
        registry.addMapping("/api/**")
                .allowedOriginPatterns("*")
                .allowedMethods("GET", "POST", "PUT", "DELETE", "OPTIONS", "PATCH", "HEAD")
                .allowedHeaders("*")
                .exposedHeaders("*")
                .allowCredentials(true)
                .maxAge(3600);
    }
}
⚠️ Key insight Use allowedOriginPatterns (not allowedOrigins) when allowCredentials(true). Spring rejects wildcards in the latter.

# Stage 1: Build Angular
FROM node:20-alpine AS build
WORKDIR /app
COPY package*.json ./
RUN npm ci

# Stage 2: Serve with Nginx
FROM nginx:stable-alpine
COPY nginx.conf /etc/nginx/conf.d/default.conf
COPY --from=build /app/dist/*/browser /usr/share/nginx/html
EXPOSE 80
CMD ["nginx", "-g", "daemon off;"]

nginx.conf:

server {
    listen 80;
    server_name localhost;
    root /usr/share/nginx/html;
    index index.html;

    gzip on;
    gzip_types text/plain text/css application/json application/javascript text/xml;

    # Proxy API calls to backend container
    location /api/ {
        proxy_pass http://backend:2002/api/;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_method $request_method;
    }

    # Angular SPA routing
    location / {
        try_files $uri $uri/ /index.html;
    }

    # Static asset caching
    location ~* \.(?:css|js|jpg|jpeg|gif|png|svg|ico|woff2?)$ {
        expires 1y;
        add_header Cache-Control "public, immutable";
    }
}

8. Key Concepts Learned

Docker

  • Multi-stage builds — build with Maven/Node, run with minimal JRE/Nginx
  • Container networking — containers reach each other by name
  • Volumes — mysql-data persists database across container restarts
  • Health checks — Docker detects when a service is ready
  • .dockerignore — keeps image small by excluding junk
  • --env-file — cleaner than many -e flags

Nginx

  • Reverse proxy — forward /api/* to another service
  • SPA routing — try_files $uri $uri/ /index.html for Angular
  • Gzip compression — smaller responses
  • Static asset caching — faster repeat visits

Spring Boot

  • Environment variables — application.properties reads ${VAR}
  • @RestControllerAdvice — global exception handling
  • JPA/Hibernate — entity ↔ table mapping
  • Bean validation — @NotBlank, @Email
  • CORS — allowedOriginPatterns vs allowedOrigins

Angular

  • Standalone components — no NgModule needed
  • Services — singleton, providedIn: 'root'
  • RxJS Observables — async data streams
  • Relative URLs — /api/users works behind proxies

Networking

  • localhost inside container = the container itself
  • Container name = DNS name on Docker network
  • Same origin = browser doesn't trigger CORS
  • Preflight OPTIONS — browser asks permission before PUT/DELETE
